# Contributing

This is an independent study tracker. Contributions should preserve source attribution and avoid reproducing material that the contributor does not have permission to share.

## Content changes

- Use concise topic labels rather than reproducing textbook passages, slides, exam questions, or answer keys.
- Identify the syllabus or public source used for any coverage claim.
- Do not describe the tracker as complete or official without evidence from the current authoritative syllabus.
- Do not submit copyrighted course assets, licensed examination material, or leaked exam content.

## Code changes

- Keep the app dependency-light.
- Validate changes to module data against the schema: a `modules` array containing numeric IDs, string titles, and arrays of string topics.
- Test progress rendering, local persistence, import/export, search, and responsive navigation.
- Do not add analytics, remote storage, or third-party scripts without documenting the data flow.

## Privacy

Do not commit personal study exports, browser data, account credentials, API keys, or environment files.
